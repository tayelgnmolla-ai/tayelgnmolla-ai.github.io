TAYELGN MOLLA PROFESSIONAL WEBSITE

1. EASY TEST:
   Extract the ZIP and double-click index.html. It opens in Chrome/Edge.

2. BETTER LOCAL TEST:
   Install VS Code -> open this folder -> install the Live Server extension -> right-click index.html -> Open with Live Server.

3. BEFORE PUBLISHING:
   Edit index.html and replace YOUR-EMAIL@example.com and YOUR-LINKEDIN with your real contact details.
   Review experience dates and any employer/project wording before publishing.

4. FREE PUBLISHING:
   GitHub Pages, Netlify, or Cloudflare Pages can host these three files for free.
